Role of Key Components

Controller Layer

RegistrationController: Orchestrates HTTP requests, maps URLs to service methods, and manages RedirectAttributes for flash messages.

Service Layer

AllocationService: Core heart of the app. Implements 2PL concurrency, seat validation, and transactional updates.

Data Layer

Entities & Repositories: Map PostgreSQL tables to Java objects and perform row-level locking (PESSIMISTIC_WRITE).

DTO & Utils

CourseInfo: Simplified object to pass course/slot details to UI without exposing internal entity structure.

Final End-to-End Workflow

1

Discovery

System fetches all active course slots and available seats for the student to browse.

2

Atomic Locking

Upon selection, the system starts a transaction and acquires database locks on all course offerings in the chosen slot to prevent race conditions.

3

Consistency Check

Verifies seat availability for EVERY course in the slot. If even one is full, the entire transaction rolls back.

4

Persistence

Increments booked counts and records the student enrollment. Result is displayed instantly on the UI.
